# Welcome to Your Digital Garden 🌱

This is a modern, high-performance static documentation site and knowledge base built with **Hugo** and synced directly from your **Obsidian Vault** using the [Hugo Sync Modal](https://github.com/rubanbalaji-g/obsidian-hugo-sync-modal) plugin.
